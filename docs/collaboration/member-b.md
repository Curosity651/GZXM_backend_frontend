## 主责范围

- `topic`：课题基本信息、唯一牵头单位、承担单位关系和有效状态。
- `indicator`：时间节点、五类指标、课题下发、单位分配与累计约束。
- `achievement`：成果记录、预审申请、投稿登记、正式材料、初审和终审。

## 对外契约

- 向 C 提供课题基本信息、成员清单、牵头单位判断的公开查询服务。
- 使用 A 的 `CurrentUser`、`TopicAccessService`、审计和文件服务。
- 不在成果模块重复实现账号、角色、文件存储或归档逻辑。

## 首批任务

1. 按 OpenAPI 实现课题与成员查询/维护。
2. 实现指标节点、课题指标与单位指标分配，校验累计值不得低于下发值。
3. 实现成果状态机和两级审批；专项指标是总量子集，不重复计数。
4. 为每个权限动作增加允许与拒绝测试，并提供给 C 的 Stub/接口测试。
