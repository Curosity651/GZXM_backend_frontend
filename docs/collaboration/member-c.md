# C：月季报、归档与工作台任务单

## 主责范围

- `report`：每课题独立规则、月报/季报、初审、终审和进度。
- `archive`：单位独立国家材料、自筹项目、目录、文件关联和归档进度。
- `dashboard`：按当前用户权限聚合待办与进度。

## 对外契约

- 使用 A 的认证、权限、审计和文件服务。
- 使用 B 的课题成员与牵头单位公开查询，不访问课题 Mapper。
- 归档材料不建立审批状态或审批记录。

## 首批任务

1. 实现每课题独立月季报规则和仅牵头单位提交约束，不为未填月份生成报告。
2. 实现月季报初审、终审及版本快照。
3. 实现每课题每单位独立国家材料清单与自定义目录。
4. 实现内部单位自筹项目；外部单位在接口和查询层均拒绝访问。
5. 实现归档进度和工作台聚合，并覆盖越权读取测试。
