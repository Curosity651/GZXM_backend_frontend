### 关键坑（重要，复用时注意）
1. **bash `source .env` 会截断 DATABASE_URL**：URL 中的 `&` 被当作命令分隔符。必须按行解析：
   `while IFS='=' read -r k v; do case "$k" in ''|\#*) continue;; esac; export "$k=$v"; done < <(tr -d '\r' < .env)`
   （tr 是为了去 CRLF 的 \r）
2. **沙箱会回收子进程**：Start-Process / Win32_Process / cmd 均被安全策略阻止；MySQL/Redis/后端/前端必须以 WorkBuddy 后台 Bash 任务（exec 前台进程）方式运行，WorkBuddy 关闭后服务会停止。
3. 前端 rolldown 原生绑定缺失（npm optional deps bug）：`npm i @rolldown/binding-win32-x64-msvc --no-save` 修复，无需删 node_modules。
4. 本机有代理（127.0.0.1:62275），curl 验证 localhost 需加 `--noproxy '*'`。
